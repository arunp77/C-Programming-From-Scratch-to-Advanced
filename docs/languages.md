# Choose Your Language

This tutorial is designed for learners who may prefer English or हिंदी while learning C programming.

The C code itself stays in English because C keywords and standard library names are fixed:

```c
int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

The explanation around the code can be read in the language that feels most comfortable.

## Available Versions

| Version | Best for |
| --- | --- |
| [English](index.md) | Learners comfortable with English technical writing |
| [हिंदी](hi/index.md) | Learners who prefer Hindi explanations with common programming terms kept in English |

## Translation Style

Technical words such as `variable`, `function`, `array`, `pointer`, `compiler`, `memory`, `input`, and `output` are usually kept in English. This avoids confusing learners with uncommon literal translations.

For example:

- English: A variable stores data in memory.
- हिंदी: `variable` memory में data store करता है।

## Suggested Path

Start with one language and stay with it for the first few chapters. Once the concepts feel clear, compare the English chapter to learn standard technical vocabulary used in interviews, documentation, and open-source projects.
