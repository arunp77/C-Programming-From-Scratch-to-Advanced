# C Programming — शुरुआत से Advanced तक

स्वागत है! यह tutorial उन learners के लिए बनाया गया है जिन्होंने पहले कभी programming नहीं की है, और जो C language को धीरे-धीरे basics से advanced topics तक सीखना चाहते हैं।

!!! note "भाषा के बारे में"

    इस Hindi version में programming terms जैसे `variable`, `loop`, `function`, `array`, `pointer`, `compiler`, `memory`, `input`, और `output` को English में ही रखा गया है। India में programming सीखते समय यही style ज़्यादा natural और useful होती है।

## यह tutorial किसके लिए है?

- आपने पहले कभी code नहीं लिखा है।
- आप C को strong foundation के साथ सीखना चाहते हैं।
- आप interviews, systems programming, embedded development, operating systems, या college subjects के लिए C सीख रहे हैं।
- आपको pointers, memory management, arrays, strings, structures और file handling जैसे topics clear करने हैं।

## कैसे पढ़ें?

अगर आप बिल्कुल beginner हैं, तो Chapter 0 से शुरू करें और chapters को order में पढ़ें। Early chapters skip मत करें, क्योंकि वही आगे pointers और memory जैसे topics को आसान बनाते हैं।

अगर आपको पहले से कोई programming language आती है, तो Chapter 0 से Chapter 2 जल्दी पढ़कर Chapter 3 से continue कर सकते हैं।
