## 📘 Who this is for

- You have **never programmed before** and want a real foundation, not just copy-pasted snippets.
- You know another language and want to pick up C specifically for systems programming, embedded development, operating systems, or interviews.
- You already know some C and want a structured reference for the trickier parts — pointers, memory management, data structures, multi-file builds.

No prior knowledge is assumed. Every term is defined the first time it's used.

---

## 🧭 How to use this tutorial

The chapters are ordered so that each one only depends on what came before it. If you are completely new to programming, start at **Chapter 0** and go in order — do not skip the early chapters, even if they look "too basic." The mental models built in Chapters 0–7 (memory, variables, control flow) are what make pointers and dynamic memory in later chapters click instead of confuse.

If you already program in another language, skim Chapters 0–2 for C-specific setup and jump to Chapter 3.

Use the navigation bar at the top (or the sidebar) to jump between sections:

- **Getting Started** — what programming and C are, environment setup, your first program.
- **Language Basics** — variables, operators, I/O, decisions, loops.
- **Core Concepts** — functions, arrays, strings, pointers, structures.
- **Intermediate Topics** — dynamic memory, files, the preprocessor, recursion.
- **Advanced Topics** — advanced pointers, data structures, multi-file projects, debugging.
- **Appendix** — quick-reference cheat sheets and practice projects.

Every chapter contains runnable code with explained, line-by-line breakdowns and the exact expected output, plus exercises at the end so you can check your understanding.
